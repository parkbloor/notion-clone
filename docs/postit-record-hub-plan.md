# 포스트잇 기록 허브 전환 계획

## 목적

일정 전용 볼트와 포스트잇 전용 볼트가 같은 `계획` 진입점을 공유해 생기는 혼란을 없앤다. 저장 구조는 바꾸지 않고, 볼트의 일간 노트 템플릿 설정에 따라 진입점과 허브 내용을 다르게 표시한다.

## 모드 판정

- 일정 허브: `planner.mode === 'daily'`이고 `dailyNoteTemplate !== 'postit'`
- 기록 허브: `planner.mode === 'daily'`이고 `dailyNoteTemplate === 'postit'`

## 화면 동작

| 위치 | 일정 허브 | 기록 허브 |
|---|---|---|
| 사이드바 하단 | `📅 계획` | `📌 기록` |
| 허브 제목 | `📅 계획` | `📌 기록` |
| 첫 작업 | 오늘 일정 보기 + 오늘 일간 노트 | 오늘 기록 열기 |
| 보조 작업 | 주간 타임라인·루틴 | 이번 달 기록 |
| 일정 HTML 내보내기 | 표시 | 숨김 |

기록 허브의 `오늘 기록`은 `월간 노트 YYYY-MM`를 열고 해당 날짜의 `dailycapture` 블록을 한 번만 보장한다.

## 데이터 안전 원칙

- 페이지, 블록, 볼트 설정의 저장 형식은 변경하지 않는다.
- 기존 일정 허브의 기능과 단축키는 유지한다.
- 포스트잇 모드에서도 기존 월간·분기 메모를 삭제하거나 이동하지 않는다.
- 일정·루틴 요약처럼 `dailycapture`를 집계하지 못하는 UI는 기록 허브의 주 작업 영역에서 숨긴다.

## 1차 완료 조건

1. 포스트잇 모드에서 사이드바 진입점과 허브 제목이 `기록`으로 보인다.
2. 포스트잇 모드에서 일정·루틴 카드와 일정 HTML 내보내기가 보이지 않는다.
3. `오늘 기록`과 `이번 달 기록`이 명확하게 보인다.
4. 일정 모드의 기존 화면에는 변화가 없다.
5. TypeScript, 관련 ESLint, diff 검사가 통과한다.

## 제외 범위

- 포스트잇 문장의 자동 분류·자동 이동
- 기존 일간 메모의 자동 변환
- 월간·분기 요약의 자동 생성
- `vault_config.json` 변경
