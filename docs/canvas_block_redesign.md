# CanvasBlock 재설계 기획서

> 작성일: 2026-03-28
> 목적: 자유 절대위치(free-form canvas) 방식 → 행/열 기반 그리드 레이아웃으로 전면 재설계

---

## 1. 배경 및 문제 정의

### 현재 방식의 문제
| 문제 | 원인 |
|------|------|
| 노드 겹침 | x,y 절대 좌표 자유 배치 |
| 스냅 오차 | 그리드/노드 스냅 로직 복잡, 완벽하지 않음 |
| 저장 데이터 무거움 | 노드마다 x, y, width, height 저장 |
| "노션 같은 느낌" 없음 | 자유 캔버스는 화이트보드 UX, 노션 UX가 아님 |
| 엣지(연결선) 복잡도 | 절대좌표 앵커 계산 필요 |

### 노션의 실제 접근 방식
노션은 블록을 자유롭게 위치시키지 않는다.
**"행(Row) 안에 열(Column)을 나누고, 열 안에 블록을 쌓는"** 구조다.
열 너비는 비율(%)로 저장하고, 구분선 드래그로만 조절한다.

## 2. 새 아키텍처

### 2-1. 데이터 모델

```typescript
// 블록 단위 (열 안에 들어가는 콘텐츠)
interface LayoutBlock {
  id: string
  type: 'text' | 'heading1' | 'heading2' | 'heading3' | 'image' | 'code'
  content: string
  color: '' | '1' | '2' | '3' | '4' | '5' | '6'  // 노드 배경색
}

// 열 단위 (행 안에서 가로로 나뉨)
interface LayoutColumn {
  id: string
  width: number        // 퍼센트 (0~100), 같은 행의 열들 합계 = 100
  blocks: LayoutBlock[]
}

// 행 단위 (세로로 쌓임)
interface LayoutRow {
  id: string
  columns: LayoutColumn[]
}

// 전체 CanvasBlock 데이터
interface CanvasData {
  rows: LayoutRow[]
}
```

### 2-2. 레이아웃 예시

```
┌─────────────────────────────────────────┐
│ Row 1 (columns: 1개, width: 100%)       │
│ ┌───────────────────────────────────┐   │
│ │ Column A  [H1: 프로젝트 개요]     │   │
│ └───────────────────────────────────┘   │
├─────────────────────────────────────────┤
│ Row 2 (columns: 2개, 50% / 50%)         │
│ ┌─────────────────┬─────────────────┐   │
│ │ Column A        ┃ Column B        │   │
│ │ [H2: 요구사항]  ┃ [H2: 일정]     │   │
│ │ [P: 내용...]   ┃ [P: 내용...]   │   │
│ │ [P: 내용...]   ┃                 │   │
│ └─────────────────┴─────────────────┘   │
│              ↑ 드래그로 너비 조절        │
├─────────────────────────────────────────┤
│ Row 3 (columns: 3개, 33% / 33% / 34%)  │
│ ┌───────────┬───────────┬───────────┐   │
│ │ Column A  ┃ Column B  ┃ Column C  │   │
│ └───────────┴───────────┴───────────┘   │
└─────────────────────────────────────────┘
```

## 3. 기능 명세

### 3-1. 행(Row) 조작
| 기능 | 트리거 | 동작 |
|------|--------|------|
| 행 추가 | 행 하단 `+` 버튼 호버 | 새 행 + 빈 열 1개 삽입 |
| 행 삭제 | 행 왼쪽 `×` 버튼 | 행 전체(열+블록 포함) 삭제 |
| 행 순서 변경 | 행 왼쪽 `⠿` 핸들 드래그 | 행 위아래 이동 (dnd-kit) |

### 3-2. 열(Column) 조작
| 기능 | 트리거 | 동작 |
|------|--------|------|
| 열 추가 | 열 우측 `+` 버튼 | 현재 열 너비를 균등 분할 |
| 열 삭제 | 열 상단 `×` 버튼 (빈 열만) | 너비를 인접 열에 병합 |
| 너비 조절 | 열 구분선 드래그 | 좌우 열 width% 실시간 조정 |
| 최소 너비 | — | 15% (너무 좁아지는 것 방지) |

### 3-3. 블록(Block) 조작
| 기능 | 트리거 | 동작 |
|------|--------|------|
| 블록 추가 | 열 하단 `+` 버튼 | 타입 선택 드롭다운 → 블록 추가 |
| 블록 편집 | 클릭 | 인라인 편집 (textarea / input) |
| 블록 삭제 | 블록 우측 `×` hover | 블록 제거 |
| 블록 순서 변경 | 블록 좌측 `⠿` 드래그 | 같은 열 내 위아래 이동 |
| 블록 타입 변경 | 블록 좌측 타입 버튼 | H1/H2/H3/P 전환 |
| 블록 색상 | 블록 헤더 색상 버튼 | 배경색 6종 + 기본 |
| **열 간 이동** | 블록 드래그 → 다른 열 | 열 간 블록 이동 (dnd-kit) |

### 3-4. 전체 기능
| 기능 | 설명 |
|------|------|
| readMode | 편집 UI 전체 숨김, 내용만 표시 |
| 빈 상태 | "클릭하여 행 추가" 안내 |
| 색상 테마 | 기존 6종 유지 (뮤트 톤으로 조정) |

## 4. UI/UX 상세

### 4-1. 열 구분선 드래그
```
열 A (50%)    열 B (50%)
┌───────────┃───────────┐
│           ┃           │
│    ←→    ┃    ←→    │  ← 구분선에 마우스 올리면 커서 col-resize
│           ┃           │
└───────────┃───────────┘
            ↑
     6px 너비 투명 hit-area
     hover 시 파란 선으로 표시
```

### 4-2. 행 추가 버튼
```
┌─────────────────────────────┐
│ Row N                       │
└─────────────────────────────┘
           [+ 행 추가]          ← 행 사이 hover 시 나타남
┌─────────────────────────────┐
│ Row N+1                     │
└─────────────────────────────┘
```

## 5. 컴포넌트 구조

```
CanvasBlock                        ← 최상위, CanvasData 상태 관리
  ├── CanvasToolbar                ← 우상단 고정 (읽기모드 토글만)
  ├── CanvasRow (× N)              ← 행 렌더링 + dnd-kit Sortable
  │   ├── RowHandle                ← 드래그 핸들 (⠿) + 삭제 버튼
  │   ├── CanvasColumn (× M)       ← 열 렌더링
  │   │   ├── ColumnResizeHandle  ← 열 우측 구분선 드래그
  │   │   ├── CanvasBlock (× K)   ← 블록 렌더링 + dnd-kit Sortable
  │   │   │   ├── BlockHandle     ← 드래그 핸들 (⠿) + 타입 버튼
  │   │   │   ├── BlockContent    ← textarea / p 태그
  │   │   │   └── BlockToolbar    ← 색상 버튼 + 삭제 버튼
  │   │   └── AddBlockButton      ← 열 하단 + 버튼
  │   └── AddColumnButton         ← 행 우측 + 버튼
  └── AddRowButton                 ← 전체 하단 + 버튼
```

## 6. 기술 선택

| 항목 | 선택 | 이유 |
|------|------|------|
| 드래그앤드롭 | dnd-kit (기존 사용 중) | 이미 프로젝트에 있음 |
| 열 너비 조절 | `onMouseDown` + `mousemove` | 기존 ResizeHandle 패턴 그대로 |
| 상태 관리 | `useState` (컴포넌트 로컬) | 외부 의존 없이 단순하게 |
| 저장 | 기존 `onChange(JSON.stringify(data))` | 인터페이스 동일하게 유지 |

---

## 7. 마이그레이션

기존 CanvasBlock 데이터(nodes/edges 구조)는 **호환하지 않음**.
기존 캔버스 블록 콘텐츠는 빈 상태로 초기화 (또는 H1 노드를 첫 행으로 변환).

---

## 8. 구현 순서

1. `CanvasData` 타입 재정의 (행/열/블록)
2. `parseCanvas()` 파서 업데이트 + 빈 기본값
3. `CanvasColumn` 컴포넌트 (블록 렌더링 + 열 리사이즈)
4. `CanvasRow` 컴포넌트 (열 목록 + 행 조작)
5. `CanvasBlock` 최상위 조립 + 툴바
6. dnd-kit 행/블록 드래그앤드롭
7. readMode 적용
8. `BLUEPRINT.md` 업데이트
